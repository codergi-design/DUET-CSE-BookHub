# 📚 DUET CSE BookHub — Used Academic Book Marketplace

**DUET CSE BookHub** is an Android application designed specifically for Computer Science & Engineering students at Dhaka University of Engineering & Technology (DUET). It allows students to buy, sell, lend, and borrow used academic textbooks easily within the campus community.

---

## ✨ Features

- 🔐 **User Authentication**: Secure Login & Sign-up using Firebase Authentication.
- 📖 **Book Listings**: Post and browse used textbooks with details such as title, author, condition, semester/year, and price.
- 🔍 **Search & Filtering**: Filter books by semester, subject, or search by name to quickly find required course materials.
- 💬 **Seller Contact**: Direct contact options for buying or borrowing books from fellow DUETians.
- ⚡ **Realtime Database**: Fast and real-time synchronized storage powered by Firebase Realtime Database.

---

## 🛠 Tech Stack & Tools

* **Language**: Java
* **UI/UX Design**: XML, Material Design Guidelines
* **IDE**: Android Studio
* **Backend**: Firebase Authentication, Firebase Realtime Database
* **Version Control**: Git & GitHub
